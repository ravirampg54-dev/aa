CREDITS

      
    

    

      
HIGHWAY RUSH

      
A 2.5D arcade motorcycle racer that runs entirely in the browser — no engine, no build step, no network.

      
HOW IT IS BUILT

      
    
        
  • Rendering — Canvas 2D with a pseudo-3D segment road renderer, a chase camera with speed-driven FOV, lag and roll, parallax silhouette layers and sprite sheets.
    • 
        
  • Art — every sprite, background and icon is generated procedurally by tools/gen-sprites.js; nothing is traced or downloaded.
    • 
        
  • Audio — the soundtrack and every effect are synthesised to WAV by tools/gen-audio.js> (subtractive synth, drum voices, reverb); the engine note is generated live with WebAudio.
    • 
        
  • Data — levels, vehicles, pickups and awards live in data/*.json and are compiled to js/data.gen.js so the game runs straight from the filesystem.
    • 
        
  • Code — vanilla ES2018 in plain scripts under js/, one concern per module, no dependencies.
    •
